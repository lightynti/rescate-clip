RESCATE CLIP - LEEME
====================

Exporta dibujos de Clip Studio Paint (.clip) a PNG a resolucion completa,
leyendo el archivo directamente, sin abrir Clip Studio. Tambien encuentra sola
la carpeta de autoguardados de recuperacion de Clip Studio.

Pagina del proyecto: https://github.com/lightynti/rescate-clip

COMO SE USA
-----------
1. Abri RescateCLIP.exe (si bajaste el .zip, deja la carpeta _internal al lado
   del .exe). La primera vez te muestra este aviso para aceptar.
2. A la izquierda aparecen los autoguardados de Clip Studio, el mas nuevo
   arriba. Tambien podes usar "Abrir otro .clip...".
3. "Exportar PNG a resolucion completa..." y elegi donde guardarlo.

Si Windows muestra "Windows protegio su PC": Mas informacion -> Ejecutar de
todas formas (el programa no esta firmado digitalmente).


RECOMENDADO
-----------
Rescate CLIP lee los autoguardados que Clip Studio escribe cada cierto tiempo.
Lo que dibujaste despues del ultimo autoguardado no aparece. En las
Preferencias de Clip Studio (seccion Archivo) baja el intervalo de los datos de
recuperacion para que el autoguardado este siempre al dia.
